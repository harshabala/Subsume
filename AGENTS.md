## Project tracking (Narada)
This repo is tracked in Narada as project "Subsume". A git hook auto-logs every commit — you don't need to call `narada progress` yourself for routine commits. You DO need to run `narada handoff --to <next-agent> --summary ... --next-steps ...` before ending any session where you're leaving work for someone else to pick up — the git hook only captures commits, not handoff context, blockers, or what to do next. Check `narada context Subsume` at the start of a session before starting work.
